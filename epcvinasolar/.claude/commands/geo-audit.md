# GEO Audit Command

Use the EPCVINA GEO SEO skill.

Run the audit script from the repo root:

```bash
node ./scripts/geo-audit.mjs
```

Then review:
- `geo-audit-report.md`
- `geo-audit-report.json`

Focus on:
- missing or duplicate titles
- missing descriptions
- dynamic pages with raw slugs
- `llms.txt`
- `robots.txt`
- sitemap reference
