# EPCVINA Marketing Docs

Thư mục này gom toàn bộ tài liệu marketing cho `epcvina.com` / `epcvinasolar` để team dễ mở, xem và dùng ngay.

Chuẩn diễn đạt cho mục tiêu cuối cùng của mọi tài liệu:
`3 chuyển đổi cuối` = khách chat Zalo, gọi điện hoặc điền form lead để lấy thông tin tư vấn.
